# yEd - Diagrams You Draw Yourself

![yEd with a small diagram the user is drawing](https://www.yworks.com/assets/images/yed/yed-header.ba9d10a13f.webp)

## Product Snapshot

yEd is a graph editor for pictures of structure: a flowchart, a family of components, or a map of a process you know. You place nodes, name them, and connect them. Layout tools can tidy a graph you already built. They should not invent nodes you did not mean to include.

Import only data you are allowed to turn into a picture. A spreadsheet of your own notes is fine. A dump of someone else's systems is not a diagram to explore. yEd does not discover hosts, and a pretty layout is not permission.

## Mount and Burn Toolkit

| Task | What you get |
|---|---|
| Nodes | Boxes you place and name |
| Edges | Lines you draw between those boxes |
| Labels | Text you can still read after a layout |
| Groups | A cluster that stays together |
| Layout | A tidy pass on a graph you already made |
| Export | A picture or a graph file under a new name |

Save the yEd file. An exported PNG is what you paste into a page. The next edit belongs in the graph, not in the picture.

## Deep Dive

Start with five nodes you can explain. Connect them. Run a layout only after the names are right. If the layout overlaps labels, undo it and try a simpler one. Do not import a file you cannot explain just because the wizard offers a format.

Keep the file in a folder you back up. A diagram of passwords or private paths is as sensitive as those secrets. Share an export, not the only copy, until you know the picture is the one you wanted. yEd will not validate that your drawing matches a real network.

## Adoption Paths

yEd fits a flowchart for a process you run, a sketch of software you are writing, or a map you were asked to maintain. It fits a single file you can diff by keeping versions. It does not fit network discovery, and it does not belong filled with data you were not given.

## Install Walkthrough

Prerequisites: A folder for the diagram, and a structure you already understand.

1. Install yEd and create a new graph in that folder.
2. Add a handful of named nodes and connect them.
3. Save before you try an automatic layout.
4. Undo a layout that hides the labels.
5. Export a picture only when the names are right. Keep the graph file.
